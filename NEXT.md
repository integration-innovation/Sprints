## Sprint 02 — ready to run

**Assess the mandatory triad from the model.** Sprint 01's next possibility, already in the target
bank of programme `B8HFVL`, suggested for Sprint 02 and owned by Woon Wei.

> Assess the mandatory triad from the model — flag the accessible entrance door, test the
> accessible toilet area, and confirm a lift or ramp serves the entrance level — so that a
> triggered project sees three findings instead of a statement.

Where it stands in the tool: the toilet test exists (the 3.06 m² necessary condition, with a
*cannot comply* finding). Entrance and route are still *not determinable* because IFC carries no
flag for which door is the accessible entrance and `OverallWidth` is a nominal leaf width. The
sprint-sized cut is to let the assessor **nominate** the entrance door and the route's lift or
ramp from the model's own lists, then test what can be tested about those — never to infer them.

Definition of done to beat: a triggered project shows three findings, each either a necessary
condition met, a *cannot comply*, or an explicit gap with the reason.

## Not doing, with the reason

- **IndexedDB instead of localStorage** — the same eviction rules apply to both; the lever is
  `navigator.storage.persist()`, which is already called on every load.
- **Background Sync** — unsupported on Safari and iOS, which is where the app is used. The
  existing queue-and-retry-on-reopen is the right design for that constraint.
- **Demo sprint data** — fake records that read as real were this week's actual failure mode.
- **A "your data never leaves your device" badge** — false once a sheet or archive is connected.
  The header already states the true storage mode.

## Known limits worth remembering

- Reminders from the sprint clock fire only while the tab is open. No browser this app targets
  gives a page a background alarm.
- The Basic Accessibility tool keeps no state between visits by design; the result is meant to be
  printed to PDF at the end.
- A shortcut cannot name a programme, so *Continue my sprint* opens the most recently created one.
